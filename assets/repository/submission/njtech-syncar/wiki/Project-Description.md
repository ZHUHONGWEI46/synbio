# Project Description · 项目描述

> **面向 1,4-丁二胺生物制造的 AI 驱动羧酸还原酶改造**

## 1. 研究问题

MAB2962 羧酸还原酶（CAR）对 GABA 的催化效率限制了由 L-谷氨酸经 GABA 合成 1,4-丁二胺的酶工程路线。本项目以三突变体 PSW 为起点，结合候选排序、高通量筛选、纯酶和全细胞验证，寻找可进一步表征的 CAR 变体。

## 2. 核心路线：用实验反馈校正 AI

项目并不将通用蛋白语言模型分数直接视为催化活性，而是按实验时间顺序建立闭环：

```text
PSW → ESM2 zero-shot → R0 实验 → 实验标签训练监督模型
    → R1 预测与实验 → R1 数据反馈并重训练 → R2 预测与实验
```

R0 的最佳相对 PSW 活性为 1.118，中位数为 0.993，42.9% 候选超过 PSW。以 R0 标签训练后，R1 的最佳实验值为 1.554，较 R0 最佳值约提高 39%；R1 的中位数为 0.884，21.3% 候选超过 PSW。将 R1 数据反馈后，在同一 R2 测试集上，FCNN 的 Spearman 由 −0.040 提升至 0.118；R2 的最佳值为 1.386、中位数为 0.906，25.5% 候选超过 PSW。

这些结果表明，真实实验反馈可改变低样本体系中部分模型的前向排序表现；它们不表示所有模型准确，也不表示新模型全面优于基线。完整的三模型、三时间划分结果见 [AI / Computational Methods](./AI-Computational-Methods.md)。

## 3. 干湿实验衔接

候选通过全细胞快筛与复筛，再对优势变体开展纯酶和全细胞催化表征。PSW-F430M 的纯酶相对活性为 1.74 ± 0.21、全细胞相对产物表现为 1.423 ± 0.039；PSW-L417A 分别为 1.61 ± 0.07 和 1.473 ± 0.142（均相对 PSW，n=3）。这些数据用于候选比较，不能直接外推为放大生产性能。

实验方法与统计说明见 [Wet Lab Experiments](./Wet-Lab-Experiments.md)，数据见 [`data/raw/`](../data/raw/) 和 [`data/processed/`](../data/processed/)，元件见 [Parts](./Parts.md)。

## 4. 高阶突变的边界分析

Round 3 的五突变数据仅作为高阶突变外推的 retrospective challenge / 方法边界分析。它不属于 R0—R2 的历史前向 benchmark，不参与正式模型训练、验证或选择，也不用于宣称额外的模型迭代效果。

## 5. 可复现性与局限

正式 benchmark 代码位于 [`src/ai/historical_benchmark/`](../src/ai/historical_benchmark/)，可读取现有 R0—R2 处理数据并生成指标、预测和协议文件。其依赖本地 ESM2-650M 缓存，且尚未证明跨蛋白、跨底物或高阶组合的泛化能力。
