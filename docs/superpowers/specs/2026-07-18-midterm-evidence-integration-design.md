# MutDesign 中期汇报实验素材整合设计

## 目标

在不改变现有 MutDesign 紧凑视觉系统和四页信息架构的前提下，整合中期汇报中已验证、非模型类的项目素材：真实 M3 FASTA、湿实验关键成果、实验图证和已知口袋位点快捷定位。

## 范围

### 真实 M3 序列

- WT 继续读取根目录 `MAB2962.fa`。
- M3 直接读取 `NJTech-SynCAR-2026-main/submission/njtech-syncar/data/raw/MAB2962 D281P-G420W-N514S.fa`。
- 加载时验证两条序列长度一致，并且仅在 281、420、514 三个位点分别为 D→P、G→W、N→S。
- 若 M3 文件读取或校验失败，回退到前端根据 WT 生成的 M3，并明确显示回退状态。

### 湿实验成果和图证

- 在“项目概览”追加“湿实验关键成果”区块。
- 里程碑独立显示：A342E +45%、N514Y +67%、D281P +100%、M3 相对 WT 4.8×。
- 明确提示这些结果来自历史半理性/组合实验批次，不能与 Round 0 的“相对 M3”数据直接合并。
- 使用中期汇报原始图片展示筛选原理、筛选流程、A342/N514、L-Ala 扫描、组合突变和 Round 0 图证。
- 图片卡片可点击打开原生对话框大图，保留文件标题和实验语境。

### 已知口袋位点定位

- 在结构与突变页面左栏新增八个位点：D281、I302、M303、G306、A342、L343、V344、V396。
- 位点按钮用于结构/序列定位，不自动生成突变，不改变当前候选的实验结果。
- 点击后 Mol* 聚焦对应残基；序列视图同步高亮并滚动到该位置；状态区说明其来源为分子对接口袋分析。
- M3 亲本下 281 位显示当前残基 P，但保留“WT D281”的证据语义。

## 数据边界

- `round_0.xlsx` 新旧版本的28条记录在业务数据上等价，不重复导入。
- A342/N514、L-Ala 和组合突变目前只有图表，没有原始数值表；仅作为图证展示，不转换成可查询表格。
- 当前交互式 mmCIF 不含 AMP；AMP 相关图片仅标记为“中期汇报静态结构图证”。
- 不添加模型分数、训练状态、结构域边界或未确认的第八个二次验证突变体。

## 视觉与交互

- 复用现有白色圆角卡片、冷灰背景、紫色强调色、11–15px 紧凑字号和独立滚动模式。
- 概览首屏结构保持不变，新增内容位于页面向下滚动区域。
- 图证卡采用固定比例裁切、完整标题和来源标签；大图对话框提供明确关闭按钮。
- 口袋位点按钮采用小型胶囊样式，并区分亲本突变位点。
