# MutDesign 真实数据工作台设计

## 目标

在现有 MutDesign 三栏界面上完成可演示的纯前端蛋白质突变设计与实验数据平台。所有科研数值必须来自本地 FASTA、AlphaFold3 JSON/CIF 或实验 Excel；AI 模型未接入时只展示接口占位，不再展示静态预测分数。

## 已确认范围

第一阶段包含四个前端工作区：项目概览、结构与突变、实验数据、批量设计。视觉系统沿用用户提供的 MutDesign 原型和当前紧凑三栏布局。

## 数据来源

- `MAB2962.fa`：1184 aa WT序列，是所有位点校验和突变序列生成的唯一基准。
- `fold_2026_07_18_14_35_model_0.cif` 至 `_4.cif`：真实AlphaFold3结构。
- `summary_confidences_*.json`：模型级ranking score、pTM、无序比例和碰撞状态。
- `full_data_0.json`：原子pLDDT、残基映射、PAE和接触概率。
- `zero-shot 初筛吸光值.xlsx`：WT/P/PS/PW/PSW和28个候选的3次重复与均值。
- `round_0.xlsx`：28个四突变体的完整序列和相对M3实验yield。

## 信息架构

### 项目概览

展示真实数据量、M3亲本、当前最佳Round 0候选、AlphaFold3模型状态和Zero-shot → Round 0 DBTL进度。尚无Round 1/2数据时显示空状态。

### 结构与突变

保留三栏工作台。左栏选择WT或M3亲本、结构模型、突变位点和目标氨基酸，并提供组合突变输入。中栏在“结构 / FASTA序列 / PAE热图”之间切换。右栏优先显示真实实验结果；AI区域固定显示“模型尚未接入”，提交按钮仅返回未配置状态。

### 实验数据

提供候选搜索、状态/高低于亲本筛选、排序、实验表格和基于3次重复值的Canvas图表。点击候选可回到结构工作台并定位对应残基。

### 批量设计

在WT或M3亲本上对一个位点生成除原残基外的19个饱和突变候选，校验位点后生成序列。支持导出CSV和多序列FASTA，数据只保存在当前浏览器会话。

## 核心行为

- 突变格式统一为 `D281P/G420W/N514S`，按位点升序规范化。
- 拒绝越界位点、非法氨基酸、原始残基不匹配和同位点重复。
- M3序列由WT可靠生成；M3仍使用WT结构定位，并显示非真实突变后构象提示。
- 结构点击/序列点击至少保证序列到结构的定位与聚焦；结构选中残基信息使用Mol*原生交互。
- `relativeToParent > 1` 显示“高于M3”，否则显示“低于M3”，不自行发明推荐等级。
- pLDDT和PAE只显示AlphaFold3原始字段派生值。

## 错误与空状态

- FASTA或结构加载失败时显示文件名和重试提示。
- 未找到实验记录时显示“待实验”，不回退到伪造分数。
- AI提交始终返回“预测服务暂未配置”。
- PAE按需载入12MB JSON，载入期间显示进度，失败时不影响结构与序列功能。

## 测试

- 单元测试覆盖FASTA解析、位点校验、组合规范化、突变序列生成、饱和突变19项、实验查询和排序。
- DOM测试确认没有虚构预测字段，存在四个工作区、AI占位、序列和实验入口。
- 浏览器测试覆盖导航、候选选择、序列位点定位、批量生成、导出入口、PAE载入、面板滚动和控制台错误。

## 非目标

不实现AI推理、ΔΔG、分子对接、突变后真实构象、永久数据库、账号权限或多人协作；不把WT结构高亮称为突变体结构。
