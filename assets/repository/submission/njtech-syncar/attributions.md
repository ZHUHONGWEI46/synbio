## 4. 开源代码 / Open-Source Code

本项目使用 ESM 系列的开源实现与接口进行蛋白序列嵌入和 zero-shot 候选排序。相关代码来源、版本和许可证应以实际使用的发布版本为准，并在最终模型运行记录中固定。
