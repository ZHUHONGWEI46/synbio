## 2. 关键访谈 / Interviews

### 访谈 #1：南京工业大学生物与制药工程陈飞飞老师

- 时间：2026年8月17日。
- 形式：线下访谈。
- 受访者背景：主要研究方向为医药中间体等含氮功能分子的酶催化合成技术开发，涉及酶基因挖掘、蛋白质工程改造、计算模拟、多酶级联反应体系构建等。
- 关键引述：“机理讨论需要把酶促羧酸活化、还原步骤与全细胞体系中的其他影响因素分开；仅比较终点活性不足以说明限制环节。”
- 这次访谈如何改变了我们的设计：在后续实验说明中补充底物、辅因子和对照组的记录；将纯酶活性与全细胞产物表现分开解释；针对候选突变体，优先记录重复数、离散度和适用条件。

### 访谈 #2：南京工业大学生物与制药工程张阿磊老师

- 时间：2026年8月17日。
- 形式：线下访谈。
- 受访者背景：主要研究方向为以酶催化技术转化低值含氮大分子（甲壳素、硝化纤维素等）合成高值含氮化学品如材料单体、功能糖等，涉及酶挖掘、酶改造及酶催化过程强化等技术。
- 关键引述：> “单个突变体在纯酶或全细胞体系中的活性提升，不能直接外推为产业化优势；还需要用底物范围、转化率、生产强度、辅因子供给和分离成本等指标验证。”
- 这次访谈如何改变了我们的设计：将评价框架从单一相对活性扩展为底物通用性、全细胞转化、产率、滴度、生产强度、辅因子供给和下游分离等指标；在结果页明确区分已测指标与尚未验证的产业化推断。

## 3. 伦理评估 / Ethics Assessment

本项目将区分模型预测、湿实验结果和产业化推断：不将 MAB2962 相关模型泛化为适用于任意蛋白或底盘；不将纯酶活性改善直接等同于全细胞或放大生产优势；公开元件、序列和数据前核对保密、知识产权和安全要求。涉及受访者身份、企业信息或未公开工艺信息时，仅在获得明确同意的范围内记录和公开。详细 AI 风险说明见 [AI Ethics &amp; Safety](./AI-Ethics-Safety.md)。

## 4. 反向影响 / Feedback Loop

> 项目获得的启发如下：

- 改变 #1：将机理分析从“相对活性提高”扩展为“酶促步骤、辅因子和实验对照的可解释记录”。
- 改变 #2：将产业化讨论从“活性提高”扩展为“通用性、全细胞转化和可放大性指标”。
