## 2. 模型的双重用途风险 / Dual-Use Considerations

### 2.1 风险识别

| 风险情形 | 当前判断 | 说明 |
|---|---|---|
| 模型可能生成可用于制造生物武器的序列 | 不适用 / 低风险 | 当前目标为 MAB2962 羧酸还原酶活性改造，不涉及病原体增强或毒素设计。 |
| 模型可能生成绕过抗药性筛选的序列 | 不适用 / 低风险 | 当前任务不涉及抗药性、病原体逃逸或临床耐药筛选。 |
| 模型可能被用于设计针对特定人群的有害产物 | 不适用 | 当前数据和任务不涉及人群、个体或临床信息。 |
| 公开模型权重可能加剧上述风险 | 待评估 | 当前提交区不包含模型权重；如后续公开，应先进行团队和 PI 审核。 |

### 2.2 防护措施

- 实验候选进入湿实验前由团队与 PI 审核。
- 当前提交区不提交模型权重、大体量中间数据或未确认的敏感材料。
- 涉及安全审批、Check-In 或新增风险时，需先归档至 `safety/` 并更新本页。

## 3. 算法偏见与公平性 / Bias & Fairness

当前模型主要服务于单一目标蛋白 MAB2962 的突变体排序，偏差主要来自实验数据量、候选空间覆盖范围和 zero-shot 模型对本体系的适配程度。后续应在训练指标锁定后补充模型失败模式和不确定性分析。

---

## 4. 可解释性 / Interpretability

当前可解释性依据主要来自结构分析、多序列比对、分子对接和突变位点实验验证。模型层面的位点重要性或不确定性分析待后续训练结果锁定后补充。
