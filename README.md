# NJTech-SynCAR 2026

NJTech-SynCAR team website for the AI–SynBio Challenge 2026.

## Local development

This is a static site. Serve the project root so the module imports and local data files resolve correctly:

```bash
npm install
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173/` in a browser.

The AI scoring interface is a presentation demo. Research pages distinguish supplied experimental evidence from planned computational work.
