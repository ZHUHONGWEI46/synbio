# MutDesign 导航动效设计

日期：2026-08-28  
状态：等待用户复核

## 目标

为 MutDesign 的顶部主导航、页面切换和设计工作台二级导航增加中等强度的动效反馈。动效需要提升点击方向感和层级关系，同时保持科研工具的克制与稳定，不使用持续循环、磁吸跟随、滚动劫持或夸张弹跳。

## 已确认方向

- 动效强度：B 档，明显但不浮夸。
- 视觉方案：A「滑轨与层叠」。
- 二级导航：固定中央工作台图标，完整菜单从图标下方向下展开；不再从中央向左右拉伸容器。
- 技术：GSAP 核心包，不使用付费插件、ScrollTrigger 或 SplitText。

## 动效系统

### 1. 顶部主导航

主导航内部增加一个不参与点击的共享选中胶囊。点击目录时，胶囊移动到目标按钮，形成连续的空间指引。

- 胶囊移动：260ms，`power3.out`。
- 胶囊只使用 `x` 和 `scaleX` 变换，不改变导航布局。
- 目标图标执行一次短时间线：`y: 0 → -2 → 0`、`rotation: 0 → ±5° → 0`、`scale: 1 → 1.08 → 1`。
- 图标总反馈控制在 300ms 内，不持续循环。
- 旧按钮文字颜色淡回普通状态，新按钮文字颜色同步切换为强调色。
- 点击当前已激活项时不重新播放页面切换，只保留轻微图标反馈。

### 2. 页面切换

页面切换只作用于当前和目标 `.page-view` 容器，不逐张卡片播放，避免数据界面显得松散。

- 旧页面：100–120ms，透明度降至 0，并向上移动 4px，`power1.in`。
- 完成退出后切换 `hidden` 状态。
- 新页面：220–240ms，从 `opacity: 0`、`y: 8px` 进入，`power2.out`。
- 结构页显示后继续调用 Mol* 的画布尺寸刷新，保持现有行为。
- 连续快速点击时，先终止未完成的页面时间线，再以最后一次点击目标为准，防止页面停在半透明状态。

### 3. 设计工作台二级导航

二级导航拆分为两个独立层级：固定的中央图标按钮，以及位于其正下方的悬浮菜单面板。

#### 结构

- `.subnav-handle` 改为真实按钮，尺寸保持 46 × 46px，提供 `aria-expanded` 和 `aria-controls`。
- 四个二级入口包裹在独立的 `.subnav-menu` 中。
- `.subnav-menu` 绝对定位在图标下方 8px，宽度按内容确定，始终以图标中心对齐。
- 面板的出现不改变页面或顶部导航的布局尺寸。

#### 展开

- 触发：鼠标进入图标或菜单区域、键盘焦点进入、触屏点击图标。
- 面板：280ms，从 `opacity: 0`、`y: -8px`、`scaleY: .92` 进入到最终状态，变换原点为顶部中央，`power3.out`。
- 菜单项：在面板开始后依次进入，初始 `opacity: 0`、`y: -5px`，每项间隔 35ms。
- 图标：展开瞬间下压 1px 后回弹，持续约 220ms，表达“打开抽屉”。

#### 收起

- 鼠标离开图标与面板的联合热区后等待 120ms；指针在延迟期返回则取消收起。
- 菜单项用 70–90ms 快速淡出。
- 面板随后在 160ms 内向上移动 6px 并淡出，`power2.in`。
- 焦点仍在二级导航内部时不得收起。
- 触屏设备再次点击图标或选择一个入口后收起。

### 4. 二级入口切换

- 当前项使用独立选中胶囊或共享指示层横向移动到新入口，持续 220ms，`power2.out`。
- 新入口图标执行 `scale: 1 → 1.08 → 1`，持续 220ms。
- 页面切换完成后保持面板短暂可见；鼠标离开或触屏选择完成后按对应规则收起。

## 代码结构

新增 `src/motion.js`，集中管理动效，避免在 `app.js` 的业务事件中散落 GSAP 调用。

模块职责：

- `initNavigationMotion()`：创建主导航指示器、二级导航状态和媒体查询监听。
- `animatePrimarySelection(button)`：移动主导航胶囊并播放图标反馈。
- `animateViewChange(fromView, toView, commit)`：串联退出、状态切换与进入。
- `openWorkbenchMenu()` / `closeWorkbenchMenu()`：管理下落菜单时间线、延迟关闭和 ARIA 状态。
- `animateSecondarySelection(button)`：播放二级入口切换反馈。
- `destroyNavigationMotion()`：移除监听器、清理定时器并终止时间线，便于测试和后续模块化。

`src/app.js` 继续负责决定“打开哪个页面”和更新业务状态；动效模块只负责“如何过渡”。两者通过明确函数调用连接。

## 依赖与加载

- 在 `package.json` 中加入 `gsap` 正式依赖并锁定到当前安装版本。
- `src/motion.js` 从本地 `node_modules` 导入 GSAP，页面不依赖远程 CDN，离线演示仍可工作。
- 若动效初始化失败，页面保留现有同步导航行为；错误只记录到控制台，不阻断页面使用。

## 无障碍与输入方式

- 读取 `prefers-reduced-motion: reduce`。开启时不播放补间和分批进入，直接设置最终状态。
- 不以悬浮作为唯一入口：键盘焦点与触屏点击都能展开二级菜单。
- 二级图标按钮必须有可访问名称，展开状态同步到 `aria-expanded`。
- Escape 键关闭菜单并把焦点返回中央图标。
- 动效不修改 DOM 阅读顺序，不在视觉移动期间禁用焦点。

## 响应式规则

- 桌面：中央图标 + 向下悬浮菜单。
- 小屏幕保持现有底部四项导航，不使用悬浮展开；仅保留点击反馈和页面淡入。
- `pointer: coarse` 环境不绑定依赖悬浮的打开逻辑，使用点击切换。

## 测试与验收

### 自动测试

- GSAP 依赖与 `src/motion.js` 被正确加载。
- 中央图标为按钮，并具备正确的 ARIA 属性。
- 二级菜单存在独立容器，不再使用宽度从 46px 拉伸到 510px 的旧实现。
- `prefers-reduced-motion` 分支可直接进入最终状态。
- 快速连续切换后只有目标页面可见。
- 现有 48 项数据与交互测试继续通过。

### 浏览器验收

- 点击六个主目录和设计工作台，选中胶囊方向正确且不跳位。
- 中央图标悬浮、键盘聚焦和触屏点击都能向下展开菜单。
- 指针在图标与菜单之间移动不会造成闪烁。
- Escape 可关闭菜单并恢复焦点。
- 四个二级入口可正常切换页面。
- 1536 × 900 桌面和窄屏布局均无水平溢出。
- 浏览器控制台无错误；Mol* 切回结构页后仍正确填满容器。

## 明确不做

- 不让图标持续漂浮、发光或循环旋转。
- 不做鼠标磁吸、视差、滚动触发或卡片级联飞入。
- 不引入 GSAP 付费插件。
- 不改变现有信息架构、颜色、字号、数据内容或导航目的地。
