# Integrated Validation · 干湿结合验证

> 本页记录 MAB2962 羧酸还原酶改造中的 DBTL 闭环进展。

---

## 1. 我们的 DBTL 闭环 / The DBTL Loop

```
Design -> Build -> Test -> Learn
   ^-------------------------|
```

- **Design**：基于同源序列比对、AlphaFold3 结构预测、分子对接和蛋白语言模型打分提出候选突变。
- **Build**：通过定点突变、单点饱和突变和组合突变构建候选 CAR 突变体。
- **Test**：使用 96 孔板全细胞催化活力筛选体系测定突变体 A435nm 信号。
- **Learn**：将实测活性数据整理为后续 AI 模型训练 / 迭代数据。

## 2. 第一轮闭环 / Loop #1

| 阶段 | 当前进展 |
|---|---|
| Design | 通过多序列比对、结构分析和分子对接筛选候选位点；获得 A342、N514、D281、G306、V396 等关键位点线索。 |
| Build | 构建单点突变体、单点饱和突变库和组合突变体。 |
| Test | A342E、N514Y、D281P 等突变体显示活性提升；D281P/G420W/N514S 三突变体在组合突变实验中表现出最高催化效率。 |
| Learn | 三突变体作为后续四突变候选评估的相对活性基准。 |

## 3. zero-shot 候选验证 / Loop #2 起点

以三突变体 D281P/G420W/N514S 为起点，使用 ESM 系列 zero-shot 打分筛选四突变候选，并完成一轮小规模湿实验验证。当前记录显示，zero-shot 候选最高活性约为三突变体的 1.12 倍，提示通用蛋白语言模型可富集部分正向突变，但仅凭 zero-shot 对本体系的区分度仍有限。

对应数据见：

- `data/raw/zero-shot 初筛吸光值.xlsx`
- `data/processed/round_0.xlsx`

## 4. 下一轮计划

- 将 zero-shot 候选实测数据回灌至训练集。
- 迭代训练 Stage 1 / Stage 2 模型。
- 输出四突变、五突变优先候选并进入下一轮湿实验验证。

## 5. 局限与未来 / Limitations

- 当前实验通量有限，候选空间仍需优先级排序。
- 当前训练指标尚未锁定，模型性能需要后续交叉验证和湿实验闭环共同确认。
